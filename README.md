# travel

旅行・昆虫観察の計画、調査資料、作業記録を保存するリポジトリです。

## フォルダ

| フォルダ | 内容 |
| --- | --- |
| `insects/` | 昆虫関連の遠征計画・調査・連絡記録。地域別フォルダと `specimen/`、`reports/` などに整理 |
| `fish/` | 魚突き・装備関連の記録 |
| `daily/` | 日付別の作業・会話記録（`YYYY-MM-DD/`） |
| `jobs/`、`career/` | 求職・キャリア関連の資料 |
| `others/` | その他の旅行資料・技術メモ |
| `prompts/` | 汎用の依頼文・調査プロンプト |
| `assets/`、`images/` | 旅行ページと画像 |

インド計画の引き継ぎは [2026-08-01版](insects/india/naturalists/引き継ぎ_2026-08-01.md) を参照してください。
