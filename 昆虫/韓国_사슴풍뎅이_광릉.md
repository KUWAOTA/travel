# Dicronocephalus adamsi（사슴풍뎅이）× 국립수목원 + 動線整理

## 6/21は遅すぎるか？　→ ギリギリだが可能性はある

**成虫発生期（연천 연구データ）：5月上旬〜6月下旬、ピーク5月下旬**

| 期間 | 状況 |
|---|---|
| 5月上〜中旬 | 出始め |
| 5月下旬 | **ピーク（最多）** |
| 6月上中旬 | やや減少 |
| 6月下旬（← 6/21はここ） | 終盤。記録はあるが少ない |

광릉の標本記録（1960-1989年）は4〜9月と幅が広い。ただし研究によって地域差・年差あり。
**6/21は「まだ出てる可能性がある」が「ピーク終わり」と思って期待値を下げておくのが正直なところ。**

### 生態的に重要な注意点

**침엽수원（針葉樹園）ではなく広葉樹林を好む種**
- 研究：「活葉樹林、海抜150m以下、近くに渓流がある場所」が好適環境
- 침엽수원での観察記録は、隣接する活葉樹林帯から飛んできた個体と思われる
- 국립수목원内では **수생식물원・습지원周辺の活葉樹林帯**、または入口付近の전나무숲エリアを重点チェック

## 6/21 動線案（光陵 → 화악산 最適ルート）

### 大枠の流れ
```
松島（11-12時出発）
  ↓ ITX-청춘（전철）
가평역（렌터카ピックアップ）
  ↓ 차로 약 45km・50분 남서方向
국립수목원・광릉（観察 2〜3時間、〜16:30）
  ↓ 차로 약 60km・1時間15分 북동方向
화악산 北側 ポイント（19-20時着）
  ↓
灯火採集（21時〜）
```

### ステップ詳細

**STEP 1：松島 → 가평역（전철）**
- 인천대입구역 or 센트럴파크역 → 인천1호선/수인분당선 → 청량리역 乗換 → ITX-청춘 → 가평역
- 所要：約3時間、運賃約12,000ウォン
- 11:30松島出発 → 14:30가평역 着
- **ITX-청춘は日曜リゾート利用で混む → 사전 코레일톡 예약推奨**

**STEP 2：가평역 렌터카ピックアップ**
- 14:30〜15:00にピックアップ想定
- Carmore（카모아）または Trip.com で예약（외국인 가능・국제면허OK업체）
- 예산：경차 1일 35,000〜50,000ウォン

**STEP 3：광릉 국립수목원（観察）**
- 가평역 → 수목원 約45km・50分 → 15:45〜16:00 着
- 閉園17:00なので **1時間以内の短時間観察**
- 차로 来園 → 반드시 사전 예약 필요（[예약 페이지](https://reservenew.kna.go.kr/)）
- ポイント：침엽수원隣の **전나무숲・습지원** 周辺の活葉樹林を流す

> もし수목원でのタイムが惜しければ、**수목원南側の광릉숲 외곽（지방도 325号線沿い）**も記録ポイント。保護区外の林道沿いは채집フリー。

**STEP 4：화악산 北側へ移動**
- 광릉（포천）→ 47번 국도 → 가평 방향 → 화악산 북측
- 約60km・約1時間15分
- 17:15出発 → 18:30〜19:00 화악산 북측 着

**STEP 5：화악산 灯火採集**
- 현지 セッティング → 21時〜採集
- 宿：가평 읍내（모텔 1박 3〜5만ウォン）or 차박
- 翌朝（6/22）：가평역 렌터카返却 or 김포공항 乗り捨て返却 → 帰国

## まとめ

**Q: 6/21は遅い？**
→ ピーク後半。「いれば儲けもの」くらいの期待値で。ゼロではない。

**Q: 狙う価値はあるか？**
→ 光陵は韓国最高レベルの곤충 다양성（3,932種記録）。6月中旬の光陵ならDicronocephalus以外にも面白い甲虫が十分ある。가는 価値あり。

**Q: 채집できるか？**
→ 수목원内は観察のみ。채집したいなら外周の保護区外林道を並行チェック。

**Q: 動線は成立するか？**
→ 가평역 렌터카 → 광릉 経由 → 화악산 で成立。사전 수목원 예약と ITX 예약を早めにやること。

## 昼行性か？ライトラで화악산でも狙えるか？

### 결론먼저

| 質問 | 答え |
|---|---|
| 昼行性か？ | **はい、昼行性** |
| ライトトラップに来るか？ | **ほぼ来ない** |
| 화악산北側（標高700m〜）でも出るか？ | **厳しい。生息環境が合わない** |

### 昼行性の根拠

사슴풍뎅이はCetoniinae（花金亀子）。このグループは基本的に**昼間に活動して花・樹液・熟した果物を食べる**。

- 「5月の風のない日、クヌギ林で昼間に多数集まる」という採集記録が多い
- 과숙バナナを昼間に設置して数時間後に確認するパターンが有効、とされている
- 夜間は通常静止して動かない

### ライトトラップへの誘引性

Cetoniinae全般にライトへの走光性が**低い〜ない**。
研究によると「ライトトラップが有効なのはDynastinae（장수풍뎅이系）、Melolonthinae、Rutelinae。Cetoniinaeはほとんど来ない」。

→ **화악산での灯火採集（ライトラ）に사슴풍뎅이が偶然混じる可能性は限りなく低い。**

### 화악산北側での生息可能性

研究データ：「海抜**150m以下**の活葉樹林、近くに渓流」が好適環境。

- 화악터널 北側（사창리방면）の標高：約**700〜900m**
- 완전に適地範囲外。高標高の針広混交林では기록 자체がない
- ミヤマ（Lucanus maculifemoratus dybowskyi）やダウリアコクワとは完全に生態的ニッチが別

### 正しい狙い方

| 方法 | 効果 |
|---|---|
| 昼間に광릉外周の広葉樹林を歩いて樹液木を探す | ★★★ |
| 腐熟バナナトラップを昼に設置して数時間後チェック | ★★★ |
| ライトトラップ | ★☆☆（期待薄） |
| 화악산でついでに狙う | ★☆☆（生息域外の可能性大） |

**結論：사슴풍뎅이は光陵で昼間に独立した時間を取って攻める種。화악산の灯火採集と同じ動線で「ついでに」は狙えない。光陵観察は6/21昼に독립미션として組む価値あり。**
