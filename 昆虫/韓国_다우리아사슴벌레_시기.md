# キンオニクワガタ（다우리아사슴벌레）発生時期調査

## 韓国語の記事から得た情報

### 主なソース
- BRIC「신기한 곤충이야기 21. 다우리아사슴벌레 이야기」（1998〜2001年の野外観察記録）
- 충우곤충박물관 도감（한국사슴벌레 분류）
- 경상남도교육청 과학교육원 곤충표본관

---

## 시기 정리（時期まとめ）

| 月 | 状態 |
|---|---|
| 5月 | **우화（羽化）** → ただし蛹室内で休眠中 |
| 6月 | 蛹室内で休眠継続。**野外にはほぼいない** |
| 7月上旬 | まだ早い |
| **7月中旬〜** | **野外活動開始** ← ここからが採集シーズン |
| **8月** | **ピーク。최성기（最盛期）** |
| 9月初め | 終盤。一部個体の記録あり |

> 記事原文：「5월에 이미 우화합니다. 우화 후 자신의 활동시기까지 번데기방에서 약 3개월 이상을 쉬는 것 같습니다. 주로 7월 중순~8월 달에 활동하며, 일부 지역에서는 9월 초에 발견되기도 합니다. 매년 8월이면 만날 수 있게 될 것입니다.」

---

## 6月20-22日（宇野さんの渡航日）は？

**確実にシーズン外。** 羽化は5月に済んでいるが、蛹室内で休眠中。野外で活動する個体は7月中旬まで出ない。

これは以前の調査結果と一致。

---

## 生息環境

- **高度：해발 500〜600m以上**（高地の広葉樹林）
- 「해발 5~600m 이상은 올라가야 발견됩니다」
- 강원도山間地帯が주요 산지（主要産地）
- 幼虫：コナラ・エノキ・サクラなどの완전히 썩은 나무（完全腐朽木）の内部

→ **화악산（1,468m）は環境的に適地**。高度も広葉樹林の組成も合っている。

---

## 採集方法

- **야간 가로등（夜間の街灯・山間の道路灯）** に飛来する → 走光性あり、ライトトラップ有効
  - 記事：「강원도의 산간지방으로 여행을 하시게 되면 밤에 가로등으로 가보세요」
- 樹液採集も可能（広葉樹の樹液に来る）

---

## まとめ：화악산での狙い方

6月は完全にシーズン外だが、**8月に化악산ポイント（Hwaaksan Rest Area Northside）を再訪すれば現実的に狙える**。

| 条件 | 評価 |
|---|---|
| 時期（8月） | ★★★ ピーク |
| 高度（화악산 700-900m） | ★★★ 適地 |
| 環境（広葉樹林） | ★★★ 適地 |
| 채집方法 | 夜間ライトトラップ ★★★ |
| 日本での希少性 | 対馬のみ。国内産との亜種差・産地もの価値あり |
