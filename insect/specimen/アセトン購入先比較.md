# アセトン購入先 コスパ比較（標本脱脂用途）

エクアドル便の大型甲虫脱脂用に **どれくらいの量を、どこで買うとコスパが良いか** をまとめた。

## 結論（先に）

| 量 | 推奨購入先 | 理由 |
|---|---|---|
| **試しに少量（500ml〜1L）** | **林純薬工業 試薬ダイレクト** または **モノタロウ（GA グリーンエース）** | 純度高い・送料も含めて安い |
| **本気の脱脂（4L 一斗缶）** | **モノタロウ GA 4L 缶 ¥3,898（税別）** | 一斗缶として最安クラス。500ml瓶を何本も買うより圧倒的に安い |
| **超大量（16L 一斗缶）** | **モノタロウ／ミスミ／価格.com 経由** | 数十頭脱脂するなら一斗缶。1L単価が最安 |
| **薬局・ホームセンター・ドンキ** | **非推奨**（除光液・ネイル用） | 純度低い／高い／少量。標本脱脂には不向き |

→ **甲虫数十頭を一気に脱脂するなら、モノタロウで4L缶を買うのがベスト**。

## 標本脱脂用途での具体的おすすめ

### 規模別

- **エクアドル便で大型甲虫 5〜10頭程度** → 林純薬 3L（¥4,750）か モノタロウ4L缶（¥3,898）
- **甲虫 10〜30頭・複数回処理予定** → **モノタロウ GA 4L 缶 一択**（1L単価 約¥1,072）
- **継続して脱脂する/ヘラクレス級複数** → 16L 一斗缶。モノタロウ／ミスミで比較

### 注意点

1. **試薬一級で十分**。特級はオーバースペック（標本脱脂は色・におい・脂が落ちればOK）
2. **ガラス容器必須**。プラ容器（PP/PE除く一般プラ）はアセトンで溶ける
3. **保管は冷暗所＋密閉**。揮発性が高くすぐ減る
4. 4L 一斗缶を買うなら **小分け用の茶色ガラス瓶（500ml〜1L）** も同時購入推奨
5. **危険物第四類**扱い。一斗缶は屋外保管・火気厳禁
