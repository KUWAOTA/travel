# エクアドル便 標本処理 購入リスト

エクアドルから届いた甲虫・鱗翅大量サンプルを良品標本に仕上げるために、現状の手持ち（シーラケース／志賀昆虫針／展翅板／展翅テープ）に加えて買うべきものをカテゴリ別に整理した。

## 前提（手持ち）

- シーラケース
- 志賀昆虫針
- 展翅板
- 展翅テープ（パラフィン紙等）

---

## 1. 軟化（リラックス）— 死後時間経過品の復活

長距離輸送＋死後経過のため、ほとんどの個体は乾燥硬化している。タッパー軟化＋酵素軟化剤の二段構えがおすすめ。

| 物品 | 用途 | 入手先 |
|---|---|---|
| **チョウケナーゼ（蛋白質分解酵素 軟化剤）** | 鱗翅・甲虫の硬化部位に少量注射すれば短時間で軟化。死後経過品の救世主 | [志賀昆虫オンラインショップ](http://www.shigakon.com/) |
| **業務用軟化液 1000ml** | 大量処理向け。湯煎で硬化した個体もこれで軟化可能。脚・触角だけ部分軟化したい時にも使える | [志賀昆虫オンラインショップ](http://www.shigakon.com/) |
| **タッパー（大小複数）／密閉容器** | 湿らせたキッチンペーパーを敷いて軟化室として使用。冷凍保存にも兼用 | [ハンズ／無印／100均でOK](https://hands.net/cate/diy/polystyrene/) |
| **キッチンペーパー／カット綿** | 軟化室の湿度源 | スーパー |
| **オキシドール／チモール（防カビ）** | 軟化中のカビ防止。長期軟化で必須 | 薬局／[モノタロウ](https://www.monotaro.com/) |
| **注射器（インシュリン用 1ml）** | 胸部に軟化液を注入。鱗翅軟化の決定打 | 薬局／Amazon |

参考: [蝶の軟化（pteron-world）](https://www.pteron-world.com/topics/specimen/specimen3.html) ／ [蟲眼鏡の蟲日記 軟化編](https://meganemushi.livedoor.blog/archives/2452940.html)

## 4. 臭い・脂対策（クサい甲虫＆大型甲虫の脱脂）

南米産大型甲虫（ヘラクレス・ゴライアスなど）や食糞・食肉系は脂が滲み出やすく、放置すると黒変・悪臭の原因に。エタノール→アセトン処理が標準。

| 物品 | 用途 | 入手先 |
|---|---|---|
| **アセトン（特級 500ml〜1L）** | 大型甲虫の脱脂。5〜6時間〜数日浸漬 | [モノタロウ アセトン](https://www.monotaro.com/) ／ Amazon（試薬扱い） |
| **無水エタノール 500ml** | 採集後のカビ拭き取り＆前処理 | 薬局／モノタロウ |
| **ガラス密閉容器（広口・大）** | アセトン浸漬用。プラ容器はアセトンで溶けるので不可 | [モノタロウ](https://www.monotaro.com/) ／ ハンズ |
| **ピンセット（耐溶剤・ステンレス）** | アセトン中の個体取り出し用 | Amazon／モノタロウ |
| **ニトリル手袋／保護メガネ** | アセトン取扱の安全装備 | モノタロウ |
| **キシロール or ベンジン（補助溶剤）** | アセトンで抜けない油向け。ヘラクレス系で効く | モノタロウ |
| **換気用ファン or 屋外作業環境** | アセトン揮発対策。必須レベル | — |

参考: [アセトン脱脂の手順](http://outsvx.com/insect/3530.html) ／ [アセトン使用上の注意点](http://outsvx.com/insect/15135.html) ／ [BRUTUS 福井敬貴のメンテナンス術](https://brutus.jp/insect-specimen_maintenance/)

## 優先購入順（おすすめ）

1. **軟化剤（チョウケナーゼ・業務用軟化液）＋タッパー** — これがないと作業が始まらない
2. **アセトン＋ガラス容器＋手袋** — 臭い甲虫処理。早めに脱脂始めないと色が抜ける
3. **追加の展翅板（モルフォ用大型含む）・展足板** — サイズ不足で作業が止まる
4. **ドイツ箱（T-WOOD T型まず2〜3箱、UVカット）** — 展翅・展足完成品から順次収納
5. **防虫剤・シリカゲル・湿度計** — 収納後の維持
