# 灯火可否とMTG論点

作成日: 2026-04-14

## 結論

- 公開情報だけでは、アルナーチャル・プラデーシュで `昆虫観察用ライトトラップ` が明示的に許可されているとは確認できませんでした。
- むしろ、保護区規制では `photographs` や `apparatus` の使用・所持を制限しうる文言があり、`自動的にOK` と解釈しない方が安全です。
- したがって、`PAP業者 + 必要なら森林 / 野生生物側` に書面確認を取る前提で進めるべきです。

## MTGで決めるべきこと

1. 今回の主目的を `観察・撮影` に置くか、`捕獲 / 採集` まで含めるか
2. 書面回答がない場合は `灯火なし` で行くか
3. 本命地域を `Ziro / Talley` と `West Kameng` のどちらから詰めるか
4. 移動優先か、虫の夢優先か
5. 有休を何日まで伸ばせるか

## ツアーオペレータへ確認すべきこと

- PAPルートと宿泊地で、夜間にライトトラップを使った昆虫観察は可能か
- 観察のみ / 撮影のみ / 捕獲して即リリース / 標本採集で可否が変わるか
- UV灯、白色灯、LED、発電機、バッテリー、延長コードの持ち込みに追加許可が必要か
- 夜間に保護区内を移動できる時間帯や立入可能エリアはあるか
- ガイド、レンジャー、エスコートの同行が必須か
- 書面承認が必要なら、どの役所名義か

## 推奨スタンス

- 第一案:
  `観察・撮影中心、採集なし`
- 第二案:
  `灯火は書面OKが出た場合のみ`
- 第三案:
  `未回答なら宿周辺の安全な範囲での観察に寄せる`
