# ラクス/RAKUS Vietnam応募 定量評価指標 v2

作成日: 2026-07-10

## 1. 目的

この指標は、次の3つを別々に判定するために使う。

1. 求人の必須要件を満たしているか。
2. 現地テックリードとして評価される材料がどの程度あるか。
3. その材料が、提出書類に十分な証拠付きで書かれているか。

点数はラクス社の実際の採点方法や内定確率を表すものではない。書類を改善する前後で同じ基準を使い、どの情報を集めると評価が上がるかを判断するための内部指標である。

## 3. 採点の原則

### 3.1 証拠レベル

各項目は、経験が頭の中にあるだけでは満点にしない。書類または候補者データベースに残せる証拠の強さで上限を決める。

| 証拠レベル | 条件 | その項目で取れる点の上限 |
| --- | --- | ---: |
| E0 | 情報なし、記憶なし | 0% |
| E1 | 「経験した」「改善した」などの主張だけ | 50% |
| E2 | 期間、対象、行動のうち2つ以上が具体的 | 75% |
| E3 | 期間、対象、本人の行動、結果が具体的で、他の経歴とも整合 | 100% |

採点表に個別の点数条件がある場合は、まず個別条件で素点を出し、その後に証拠レベルの上限を適用する。

例:

- 「新人を指導した」だけならE1で、育成項目の半分まで。
- 「2025年11月から2026年1月、新人1名に3サイクルの課題とレビューを実施」ならE2以上。
- さらに受講者の具体的な変化や第三者の評価が確認できればE3。

### 3.2 数字の扱い

- 月数は、同時並行案件を重複加算しない。
- 未完了のリリースは「予定」とし、完了実績と同じ点を付けない。
- 「大幅削減」「3倍」等は、測定方法を説明できなければE1扱いにする。
- 組織全体への展開がない個人利用を「標準化」と数えない。
- 役職名が不明な場合、「主任」「リーダー」として加点しない。

## 4. 足切り判定

100点評価の前に、必須要件と書類の信頼性を判定する。

| Gate | 合格条件 | 現状 | 判定 |
| --- | --- | --- | --- |
| G1 Web開発3年以上 | 月単位の案件一覧で、重複を除き36か月以上を確認できる | 3年以上との旧記載はあるが、案件別月数が未整理 | 条件付き |
| G2 海外勤務意欲 | 半年から1年の東京勤務後にベトナム赴任する意思を明記できる | 海外勤務意思は強い | 合格 |
| G3 異文化/海外生活適応 | 具体例を2件以上説明できる | タイ約1.5か月、25カ国渡航、英語での技術対話 | 合格 |
| G4 経歴の整合性 | 期間逆転、実績/目標の混同、役割の誤記が0件 | 添削用v0.7で既知の矛盾を補正。正確な開始年月等は会社PCで確認予定 | 条件付き |

判定ルール:

- G1からG3のいずれかが不合格なら、求人適合度の上限は59点とする。
- G4が不合格の間は、転職エージェントへの添削依頼は可能だが、企業への直接提出は不可とする。
- 「条件付き」は、事実がないのではなく、証明に必要な情報が不足している状態を表す。

## 9. 採点更新ルール

1. 新しい回答を得たら、該当するIDだけを更新する。
2. 点を上げるときは、根拠となる案件、期間、人数、成果物を併記する。
3. 予定が完了実績になったときだけ、リリース点を更新する。
4. エージェントのフィードバックは「市場側の評価」として別欄に記録し、この内部採点を無条件に上書きしない。
5. 企業提出直前にG1からG4、100点評価、20点完成度を再計算する。
