# 現年収625万円とラクス求人678万円の位置づけ

作成日: 2026-07-13

## 結論

ラクス求人の年収678万～966万円は、一般的な若手エンジニア求人としては高めだが、本人にとって下限678万円は大幅な年収アップではない。

- 現年収625万円→求人下限678万円: **+53万円、+8.5％**。
- 月平均の額面差: 約4.4万円。
- 税・社会保険を考えると、手取り増はこれより小さい。
- しかも求人下限には20時間分の固定残業代57,500円／月が含まれる。

したがって、下限678万円だけを見て「高年収転職」と評価するのは適切ではない。本人にとっては、給与よりも「ベトナム駐在」「現地テックリード」「育成・プロセス改善」という役割変更の大きさが目立つ求人である。

## 村田製作所で625万円は高いのか

かなり良い水準と考えてよい。

村田製作所の2025年3月期有価証券報告書では、提出会社の平均年間給与は803.1万円、平均年齢40.1歳、平均勤続14.1年である。平均給与は賞与・基準外賃金を含むため、本人の625万円とも比較しやすいが、年齢・等級が大きく違う点には注意が必要である。[村田製作所 第89期有価証券報告書](https://corporate.murata.com/-/media/corporate/about/newsroom/news/irnews/irnews/2025/0624/murata89gorep.ashx)

本人は2022年入社で、大学院修了後4年程度の段階で625万円に達している。村田全社平均803.1万円には届かないものの、40歳平均と比べる数字ではない。若手・経験4年程度という条件では、625万円はすでに強い給与水準である可能性が高い。

これは「メーカーだから誰でもゆるく高給」というより、次の要因が重なっていると見る方が正確である。

- 村田製作所が、一般的なメーカーではなく世界大手の高収益電子部品メーカーである。
- 大学院卒の総合職として入社している。
- 大企業の賞与、手当、福利厚生が総年収を押し上げる。
- 残業代が含まれている場合、その分も年収へ反映される。

仕事の負荷が本人の体感として緩やかである可能性と、給与水準が高い理由は分けて考えるべきである。公開データだけから「ゆるいから高給」とは判断できない。

## ラクスの678万円は会社内で高いのか

2025年3月期のラクス提出会社平均は648.6万円、平均年齢32.5歳である。求人下限678万円は全社平均を約29万円上回るため、ラクス社内でも平均よりやや上のレンジである。ただし全職種平均なので、テックリード職との直接比較には使えない。[ラクス有価証券報告書の従業員データ](https://edinetdb.jp/company/E31878/text)、[ラクス公式IR・有価証券報告書](https://www.rakus.co.jp/ir/securities-report/)

求人上限966万円は明確に高い。一方、下限678万円は本人の現年収と近く、「テックリードへ役割を上げる対価」として見ると強い条件とは言い切れない。

## 本人にとっての妥当な希望年収

現年収625万円から転職し、半年～1年後に海外赴任、現地テックリード、育成、プロセス改善まで担うなら、次の考え方が妥当である。

| 希望額 | 現年収比 | 評価 |
| ---: | ---: | --- |
| 678万円 | +8.5% | 最低ライン。役割拡大に対する上昇幅は小さい |
| 720万円 | +15.2% | 転職リスクを考えた現実的な下限候補 |
| 750万円 | +20.0% | 役割拡大を踏まえた希望額として説明しやすい |
| 800万円 | +28.0% | 強気。テックリード適合を高く評価された場合の交渉水準 |

現時点では、エージェントへ次のように伝えるのがよい。

> 現年収は625万円です。海外赴任と現地での育成・リード業務まで含むため、希望は750万円前後ですが、役割期待、赴任手当、社宅、評価制度を含む総条件で相談したいです。

希望750万円は求人レンジ内であり、現年収から20％増なので無理な要求ではない。ただし、正式なリーダー経験がないため、企業から下限寄りを提示される可能性はある。

## 年収以外に必ず確認する条件

この求人では、額面年収だけでなく次を確認しないと実質的な得失を判断できない。

1. 678万円に赴任手当・出張手当が含まれるか、別途支給か。
2. ベトナム社宅の家賃、水道光熱費、家具、税務上の扱い。
3. 日本とベトナムの所得税・社会保険の会社負担と手取り保証。
4. 一時帰国費用、引越費用、ビザ、医療保険、家族帯同費用。
5. 東京勤務中と赴任後で給与・手当がどう変わるか。
6. 賞与算定、評価制度、昇給時期。
7. 固定残業20時間と実際の平均残業時間。
8. 帰任後の職位・給与・配属。

社宅と赴任手当が別支給なら、額面678万円でも実質的な待遇は現年収625万円を大きく上回る可能性がある。逆に、手当込みで固定残業も増えるなら、差は小さい。

## 確率評価への影響

先の合格確率で「高年収求人」と書いた箇所は修正した。選考難度が高いと見た理由は給与額そのものではなく、現地テックリードとしてコードレビュー、育成、Agileを含むプロセス改善、技術選定、チームリードを求める役割の広さである。

現年収625万円であることは、企業側にとっても下限678万円で採用しやすい一方、本人側には大幅アップにならない。合格確率は大きく変えないが、入社判断と希望年収の設定は見直すべきである。
