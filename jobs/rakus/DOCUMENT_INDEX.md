## 現時点の面接対策完成度

完成度は、60～90秒の回答と深掘り対応に必要な情報量の概算であり、選考通過確率ではない。

| 項目 | 完成度 | 状態 |
| --- | ---: | --- |
| 理想・現状・差分 | 80% | 回答案の文章化へ移行可能 |
| キャリアパス | 80% | 深掘り注意。役割の実像はエージェント確認 |
| 転職理由 | 85% | 本音の出し方はエージェント確認 |
| 成功体験 | 80% | 新入社員教育を使用 |
| 強み | 85% | 育成時の問いかけを使用 |
| 失敗体験 | 85% | Pifaa初回リリースを使用 |
| 弱み | 10% | エージェント確認待ち |
| 志望動機 | 80% | 安定性の表現をエージェント確認 |
| 逆質問 | 60% | エージェント確認待ち |
| 海外適応性 | 85% | イタリア技術者との協働を使用 |
| 技術力の説明 | 85% | 代表事例の選択のみ |
