# 穴分析：課長との相談で詰めるべき観点

## 現在のストーリー
- 最近、人生の大事な決断を考えている
- 彼女との結婚を視野に → 来年までのタイムリミット
- その中で海外経験を考えている（JICA など）
- 会社経由で海外派遣できる可能性を探り探りで引き出したい

---

## 🔴 穴1：「なぜ海外なのか」の動機

### 課長からの想定質問
「何で海外に行きたいの？」

### 現在の説明の弱さ
グローバル視点、社会貢献など、一般的すぎる。課長レベルだと「はて、これまでそんな話聞かなかったな」と思う可能性が高い。

### 詰めるべき観点

#### ① 人生の転機における自己検証
```
「今の自分の仕事スタイルが本当に自分に合ってるのか、
別の環境で試してみたい。特に国際協力の現場で、
電子部品以外の価値提供ができるのかを知りたい」
```

#### ② 結婚前の価値観共有
```
「彼女と人生の大事な決断をする前に、
一緒にグローバルな環境で経験を積んで、
お互いの価値観を深掘りしたい」
```

#### ③ 仕事以外の社会貢献の形
```
「村田での仕事は好きだけど、個人として
直接的に困ってる人を助けるような貢献の形も
試してみたい。JICA はそのチャンス」
```

#### ④ キャリア設計への考え
```
「30代前半のこの時期に異なる視点を持つことで、
その後のキャリア（村田での復帰 or 別の道）の
選択肢が広がると考えている」
```

### 課長に伝える際のトーン
- 衝動的ではなく、考えたうえの選択
- 人生設計の一部としての海外経験
- 帰国後も「何らかの形で」会社や社会に貢献する前提

---

## 🔴 穴2：JICA vs 会社派遣の位置づけ

### 課長が「会社で海外派遣できるかも」と言った場合の対応

現在は「ワンちゃん受かったら行くかも」という曖昧さを活用して、
会社派遣を引き出そうとしている。しかし、実際に選択肢が出た時に、
どう判断するのかを自分の中で整理しておく必要がある。

### 詰めるべき観点

#### ① 期間
- JICA：2年間の固定期間
- 会社派遣：期限不明確

**問い**：「期間の融通性はどちらが重要か」

#### ② 自由度
- JICA：個人の意思主導、帰国時期の選択肢
- 会社派遣：会社の都合に左右される可能性

**問い**：「現地での自由度は人生設計にどう影響するか」

#### ③ 帰国後のキャリア
- JICA：帰国後のポジション未確定
- 会社派遣：帰国後は村田に戻る or 別ポジション

**問い**：「帰国後、キャリアの不確定性はどこまで許容できるか」

#### ④ 彼女との同行可能性
- JICA：配偶者の同行は制度上可能か確認が必要
- 会社派遣：会社規定次第

**問い**：「彼女の京大ポスドク身分との兼ね合いはどうするか」

#### ⑤ 「本当に望んでいるのは何か」の自覚
```
実は「会社派遣」という「安定版」を欲しているのか？
それとも「JICA」という「人生の転機」を欲しているのか？

これを曖昧なままにしておくと、
課長が「派遣できるよ」と言った時に
選択で迷う。
```

## 🔴 穴3：結婚と海外経験のバランス

### 彼女の状況（京大ポスドク）
- 現在の身分的・時間的制約が強い
- 来年までのタイムリミットの理由が何なのか
  - ポスドク期限？
  - 結婚のタイミング？
  - 両方？

### 詰めるべき観点

#### ① 彼女の意思確認
```
「海外に行きたい」というのは、
あなたの希望だけか、彼女もそれを望んでいるのか。

もし「あなたが行きたい」なら、
彼女はどうするのか。
```

#### ② 長期分離の現実性
- 彼女が京大に残る場合、2年間の別居になる
- その間に結婚するのか、帰国後に結婚するのか

#### ③ 共同体験 vs 個人の挑戦
```
「結婚を視野に」というなら、
一緒の時間を重視するのか、
それぞれの挑戦を尊重するのか。

この価値観が違うと、後で揉める。
```

#### ④ 親世代の納得
- 実家の親はこの計画を知っているのか
- 彼女の親はどう考えているのか

## 🔴 穴4：課長からの反発点への対応

### 課長が「現職で頑張れよ」と言った場合

現在のあなたは村田で「経験を積んでいる段階」なので、
課長からは「もっと今の仕事を深掘りしなよ」という反応が
自然に出る可能性が高い。

### 詰めるべき観点

#### ① 現職での満足度を整理
```
村田での仕事が「つまらない」わけではなく、
「人生設計の中での位置づけを見直したい」
という、別の次元の話であることを明確にする。

「今の仕事に不満」ではなく
「別の選択肢を試したい」という伝え方。
```

#### ② 30代に向けた人生設計
```
「今、30歳に向かう時期に、
複数のキャリアパス（国際協力、グローバル経験、etc）を
実際に試しておくことで、
その後の30代の選択肢が広がると考えている」

→ 40代、50代を見据えた長期キャリア設計の話として伝える
```

#### ③ 帰国後の会社への貢献
```
「海外経験を積んだ後、もし村田に戻るなら、
その経験を活かして、会社のグローバル化
（製造業としての海外展開、現地パートナーシップ等）
に貢献したい」

→ 個人の成長が会社の成長につながる道を示す
```

#### ④ 現職での育成投資の回收
```
課長が「これまで育ててきたのに…」という反発をした場合：

「村田での経験と新しい視点の組み合わせで、
より高いレベルの貢献ができるようになると考えている。
人材育成としても、それが回収である」
```

## 相談の際の進め方

### Phase 1：現状の情動的な部分を先に出す
```
「最近、彼女との結婚について真面目に考えてて、
来年までに決めなくちゃいけなくなった。
その中で、人生の大事なことを改めて考えてるんですよ」

→ カジュアルな出だし。課長にも「人生の大事な決断」
   という親しみやすい文脈を理解させる
```

### Phase 2：まだ詰まっていない、模索段階を示す
```
「海外経験も視野に入れてて、いろいろ考えてるんですけど…」

→ 「決めた」ではなく「考え中」というニュアンス
```

### Phase 3：課長の反応を見て、深掘り
```
- 課長が「そうか、頑張れ」と応援的なら → 会社派遣の可能性を探る
- 課長が「何で海外なの」と聞いてくれたら → 上記の動機づけを話す
- 課長が「現職で頑張りなよ」と言ったら → 人生設計の話に切り替える
```

---

## 最後に：自分たちの中での合意が必須

実は、課長との相談よりも先に、**彼女との相談**をもっと詰める
ことが重要かもしれません。

- 結婚のタイムリミットが「来年まで」なのはなぜ？
- 彼女は海外経験に賛成しているのか？
- 2年の別居は受け入れられるのか？
- 帰国後のキャリア（現職復帰 vs 別の道）について、合意は取れているか？

ここが甘いと、課長との相談がうまくいっても、
後で彼女との間で揉める可能性がある。
