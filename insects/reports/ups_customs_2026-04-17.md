# UPS エクアドルからの昆虫標本 — インボイス不備への対応

## 状況
- エクアドルから昆虫の荷物がUPSで到着
- 大阪の税関で止まっている
- 理由：インボイスの品物説明が不十分
- UPSが荷送人または荷受人からの追加情報を待っている

## やるべきこと

### 1. UPSに連絡する（最優先・今日中）
- **UPSカスタマーセンター**: 0120-271-040（平日 9:00〜18:00）
- 追跡番号を伝え、「インボイスの補足情報を提供したい」と申し出る
- UPS側から「何の情報が必要か」を具体的に教えてもらえる

### 2. 提供が必要になる情報（典型的なもの）

| 項目 | 記載例 |
|------|--------|
| **品名の詳細** | "Dried insect specimens for personal collection"（乾燥昆虫標本・個人コレクション用） |
| **学名・種名** | 例: Dynastes hercules, Morpho menelaus など |
| **数量** | 例: 10 specimens |
| **商業価値** | 例: USD $50（個人用で非商用であることを明確に） |
| **用途** | Personal hobby / Private collection（個人趣味・コレクション） |
| **CITES該当の有無** | ワシントン条約の対象外であることの確認 |

### 3. 注意点

#### ワシントン条約（CITES）
- エクアドル産の昆虫は**CITES附属書に掲載されている種がある**
- 該当種の場合、輸出許可証（CITES permit）が必要
- 許可証なしだと通関不可・没収の可能性あり
- 甲虫類（カブトムシ・クワガタ）は多くが非該当だが、一部の蝶（モルフォ等）は要確認

#### 植物防疫法
- 乾燥標本であれば通常問題なし
- 生体の場合は植物防疫所の検査が必要

### 4. 荷送人（エクアドル側）にも連絡
- 荷送人にも「インボイスの補足説明を送ってほしい」と依頼する
- **荷送人・荷受人の両方から情報を出すと処理が速い**

## 対応の流れまとめ

```
1. UPSに電話（0120-271-040）→ 必要情報を確認
2. 品名・学名・数量・価値・用途を書面で提出（メールまたはFAX）
3. 並行して荷送人にも補足インボイス作成を依頼
4. CITES該当種がないか確認（該当なら許可証の有無を確認）
5. 情報提出後、通常1〜3営業日で通関完了
```

## 補足
放置すると保管期間超過で返送・廃棄されるリスクがあるため、**今日中にUPSに電話するのがベスト**。
