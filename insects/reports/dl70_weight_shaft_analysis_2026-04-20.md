# DL70の重量と手銛シャフト固定の可否 — エンジニアリング判断

**作成日**: 2026-04-20
**背景**: v2でDL70を「パターンA: 手銛シャフト固定」の主力に置いたが、DL70は585g（電池込）と一般的な魚突きライトの3倍。ユーザー指摘「このくらい重いと手銛に着けるの不利にならないか？」への回答。

---

## 0. 結論

**Yes、DL70の585gを手銛シャフトに常設するのは不利**。

- 水中見かけ重量は**約320g**（浮力控除後）
- 一般的な手銛（500-700g）に**+300g = 総重量50%増**
- 光軸・銛軸を合わせる価値はあるが、**代償が大きすぎる**ケースが多い

→ **推奨戦略を変更**：DL70はハンドヘルド主力、**手銛シャフトには別の軽量ライト**を装着する二灯体制が合理的。

---

## 1. 重量の物理

### 1-1. 空気中 vs 水中

| 項目 | 値 |
|---|---|
| DL70 空気中重量（26650×2込） | **585g** |
| DL70 体積（推定） | ヘッド部 Ø60×40mm ≈ 113 cm³ + 胴部 Ø33×170mm ≈ 145 cm³ = **約260 cm³** |
| 海水排除重量（比重1.025） | 260 × 1.025 ≈ **267g** |
| **水中見かけ重量** | 585 - 267 ≈ **320g**（負の浮力、沈む） |

### 1-2. 手銛全体に与える影響

| 項目 | 値 |
|---|---|
| 一般的な手銛（Φ20mm×180cm、ステンレス+カーボン） | 空気中 500-700g、水中 200-400g |
| DL70を装着した場合の総重量（水中） | 520-720g = **50-100%増** |
| 重量中心位置 | シャフト中央付近にDL70を付けると、光軸確保のため前寄り固定になりがち → **ノーズヘビー化** |

## 2. 具体的な不利の内訳

### 2-1. スイング慣性の増加（aim tracking）
- 動く魚の追尾で銛先を振るスピードが落ちる
- **モーメント的には** DL70を先端寄り（手元から100cm位置）に付けた場合、慣性モーメント増は約 0.32kg × (1.0m)² = 0.32 kg·m² → 水中粘性抵抗と相俟って**追尾速度が10-20%低下**する計算
- 夜間の眠っているハタ・ウツボを撃つ静的射撃には影響小だが、回遊魚・泳いでいる魚には致命的

### 2-2. 腕疲労（長時間保持）
- 素潜り1本=1-2分のホールドでも、水中320gを片手先端で支える感覚は重い
- 2-3時間のセッションで**前腕の乳酸が急速に蓄積** → 後半の命中精度が落ちる
- 夜潜りは視界が狭くターゲット機会が限られる割に、疲労で撃ちミスが増えると本末転倒

### 2-3. シャフトバランスの破綻
- 手銛は「手元で垂直方向のブレを抑え、先端で水平方向に振る」動作が基本
- DL70を先端寄りに付けると**ノーズヘビー**で先端が下がりやすい
- 対策で手元寄りに付けると**光軸が銛先と一致しない**（光の主光軸が手元側を向く）→ マウントの意義が半減

### 2-4. クランプ強度への要求
- 320g×銛振りの加速度（突発1-2G）= **瞬間600-900g の剪断力**
- U字ボルト+ゴム緩衝の摩擦だけでは滑る可能性 → **機械的な係止（ピン・凸部）**が必須
- v2のU字ボルト構成はこの点で**経年ずれリスクあり**

### 2-5. 銛先を岩にぶつけた時の衝撃伝播
- 585gが衝突時の慣性で逆方向に振られる → シャフト・クランプ・ライトすべてに負担
- ライト自体は水深100m防水で衝撃耐性ありだが、**クランプ緩みの検査が毎潜必要**

---

## 3. シャフト固定がワークするケース・しないケース

### ワークするケース（許容）
- **静的な穴撃ち主体**（ハタ、アナゴ、イセエビ探し）
- **短時間セッション**（30分-1時間）
- **大型魚ターゲット**で慎重な接近が前提
- **スピアガン（ゴム式）で反動駆動** → 腕の保持力が不要、ガンがセミ自立

### ワークしないケース（不利顕著）
- **回遊魚ターゲット**（アジ・サバ・小型カンパチ等）
- **長時間セッション**（2時間以上）
- **ポール型手銛（手突き）**で腕全体で振る運用
- **潮流が強く片手で岩を掴む必要**がある状況

ユーザーのエクアドル遠征は**夜間×穴撃ち×素潜り**なので、「ワークするケース」寄り。しかしDL70の重量は**同クラスで最重量級**（BTS Flame 180g、OrcaTorch D710 240g、BigBlue VL8000P 475gと比較）。

## 4. 代替戦略：重量を手銛から逃がす

### 戦略I【推奨】二灯体制 — DL70はハンドヘルド、シャフトには軽量機

| 用途 | ライト | 重量 | 備考 |
|---|---|---|---|
| 主力：広域スキャン・穴覗き・陸上兼用 | **Wurkkos DL70（ハンドヘルド）** | 585g（空中）/320g（水中） | 手首ランヤードで確保 |
| 副：手銛シャフト固定（穴撃ち即射用） | **OrcaTorch D550（1000lm）** または **BTS Flame 1050lm** | 170-180g（空中）/80-90g（水中） | DL70の1/3重量、クランプも既存25-31mmが流用可 |

**効果**:
- シャフト重量増は**水中+80g程度**、許容範囲
- DL70の13,000lm全出力をハンドヘルドで自由に振れる
- 穴撃ち時は副灯で光軸確保、撃ちながらDL70で範囲照射も可能
- 副灯は¥5,000-15,000で選択肢豊富

**追加コスト**: ¥10,000-20,000（副灯本体 + 25-31mmクランプ）
**総予算**: v2想定¥21,500 + ¥15,000 = **約¥35,000**

### 戦略II【ミニマル】DL70のみ・ハンドヘルド運用に徹する

- シャフトマウントを諦め、DL70を常に手で持つ
- 射撃時は銛を両手で保持、ライトは手首ランヤードでぶら下げ
- 光軸が銛軸と一致しない分、**射撃精度は落ちる**が、穴撃ちは「範囲照明＋勘撃ち」で成立する
- **追加コスト0**、v2の周辺部品（ジャックナイフ+U字ボルト）も不要に

**追加コスト**: -¥8,500（周辺部品不要）
**総予算**: **約¥13,000-16,000**（DL70本体のみ）

### 戦略III【妥協】DL70を短時間のみシャフトマウント

- 普段はDL70をハンドヘルド、**穴発見時のみ数秒でシャフトにスライドマウント**
- 蝶ナット+ワンタッチクランプで脱着を3-5秒に短縮
- 疲労軽減と光軸確保を両立
- ただし**脱着の手間**が発見-射撃タイミングをロスさせる可能性

**追加コスト**: v2のまま
**総予算**: **約¥21,500**

### 戦略IV【最適化】DL70を買い直す（非推奨）

- DL70をやめ、より軽量な高出力機（OrcaTorch D710 3000lm = 240g、Sofirn SD01 Pro 10000lm = 350g）に切替
- しかしDL70のコスパ（13,000lm @ ¥15,000）は市場で突出しており、**買い直しの合理性は薄い**
- 既に購入検討を進めているなら**この選択肢は採用しない**

## 5. 推奨: 戦略I（二灯体制）

### 理由
1. **重量問題を根本解決**：シャフト搭載は80g程度に抑制、DL70を自由に使える
2. **バックアップ体制**：素潜りでのライト故障は重大事故、2本体制は安全ルール（夜間スピアの業界標準 "最低2本"に合致）
3. **機能分離で明確**：「探索=DL70、射撃=副灯」と役割分担することで、現場判断が速くなる
4. **予算妥当**：+¥15,000で実用性が大幅向上
