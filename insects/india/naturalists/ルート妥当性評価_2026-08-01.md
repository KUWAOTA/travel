# Odontolabis遠征のルート妥当性評価

作成日: 2026-08-01  
対象期間: 2026年8月8〜15日（2名）  
図: [route_evidence_map_2026-08-01.drawio](route_evidence_map_2026-08-01.drawio)

## 結論

Serenity Garden / Misty Viewsを8月8〜10日の固定軸にする判断は妥当です。その後は、現時点で地名だけを先に決めるのではなく、次の条件分岐で決めます。

1. **Honey Valley自身から、8月11〜15日の空室、ownerによる持込UV＋白幕の許可、4WD時刻が文章で確約されたら、Serenity 2夜＋Honey Valley 4夜を本命にする。**
2. Honeyが不成立で、IISERのhostと正式な夜間同行が取れたら、Serenity＋Periyar＋IISERの南部ルートにする。
3. HoneyもIISERも未確定なら、北へ大きく移動せず、Serenity＋Periyar＋許可を得た森林系私有宿からTRVへ抜ける。

今回の最優先が「Odontolabisに遭遇すること」であるため、Honeyが正式に成立した場合は、IISERの短時間1夜よりHoneyの4夜を上に置きます。IISERで**2夜の正式同行**が取れ、反対にHoneyの灯火が短時間・場所制限付きなら、南部ルートへ逆転させます。

## 評価方法

「有望」を一つの印象点にせず、次の4軸に分けました。各5点は順位づけのための相対評価であり、昆虫の出現確率そのものではありません。

- **対象根拠**: 同一地点・同時期のOdontolabis記録や信頼できる実見。
- **許可・同行**: owner、施設、大学等から合法的に夜間観察できる確度。
- **有効観察夜**: 雨や到着遅延を吸収できる夜数と、実際に灯火を見られる時間。
- **交通**: 空港・バス拠点からの接続、長距離移動や最終送迎のリスク。

## 接続の妥当性

### 共通の入口: Mumbai → Kochi → Serenity

```text
8/7  Mumbai着・空港周辺泊
8/8  BOM早朝便 → COK午前着 → 予約taxi 4〜5時間 → Misty Views
8/8・9夜  Serenity Garden
```

COKからSerenityは道路距離約143kmです。平常時の経路計算より、モンスーンの山道を考慮して4〜5時間を置きます。COKへ11時までに着く便を選べば、8日夜は遅延時の予備、9日夜を本番にできます。

- [CIAL公式prepaid taxi案内](https://cial.aero/Our-Facilities/Transportation/Prepaid-Taxi/)
- [CIAL公式予約](https://prepaid.cial.aero/)

### 本命条件付き: Serenity → Honey Valley

```text
8/10夕方  Serenity → KumilyまたはKattappana
8/10夜    Kannur行き夜行bus
8/11朝    Kannur → 予約した片道taxi → Honey指定集合地点 → 宿4WD
8/11〜14夜 Honey Valley（4夜）
8/15朝    最初の4WDで下山 → 片道taxi → IXE → BOM、Mumbai泊
```

SerenityからHoney Valleyは道路で約480kmあり、昼の車移動では10〜12時間を見込む必要があります。これは「近い二地点をつないだルート」ではありません。しかし、8月10日の夜を夜行バスに使えば、観察可能な8月11〜14日の4夜を失わずに済みます。

Kumily / KattappanaからKannurへの掲載便はありますが、8月10日の販売・座席・運行は予約画面で再確認します。Kannurから先は公共バスでIritty、Virajpet、Kakkabeへつなげますが、夜行直後の2名＋灯火機材と宿4WDの接続を考え、ここだけは片道taxiが妥当です。

- [Kumily→Kannur（redBus）](https://www.redbus.in/bus-tickets/kumily-to-kannur)
- [Kattappana→Kannur（ixigo）](https://www.ixigo.com/buses/kattappana-kannur-sts)
- [Kannur→Coorg one-way taxi](https://www.savaari.com/kannur/kannur-to-coorg-cabs)
- [Honey Valley公式予約](https://www.honeyvalley.in/booking-and-cancellation)
- [Coorg→Mangaluru one-way taxi](https://www.savaari.com/coorg/coorg-to-mangalore-cabs)
- [IndiGo](https://www.goindigo.in/)
- [Air India Express IXE→BOM](https://flights.airindiaexpress.com/en-in/mangaluru-to-mumbai-flights)

### 南部代替: Serenity → Periyar → IISER → TRV

```text
8/10〜11  Thekkady / Periyar 2泊、公式night walk 1回
8/12      Vithuraへ車移動（雨天5〜6時間程度を確保）
8/12〜15  Vithura周辺泊。hostが確定した夜だけIISERへ
8/15      TRV → BOM、Mumbai泊
```

長距離夜行バスと州境越えがなく、地理的には最も素直です。IISERの2025年8月11日記録は時期まで一致しますが、大学は観察記録があるだけで一般旅行者が自由に夜間入構できる場所ではありません。host、24時間前までの来訪登録、同行時間を確定して初めて「有望地点」から「使える地点」になります。

- [IISER visitor entry rules](https://dosa.iisertvm.ac.in/rules-notices/visitors-entry-request)
- [IISER contact](https://www.iisertvm.ac.in/pages/contact)

## 今後の連絡で変わるのは3点だけ

1. **Misty Views / Anand**: 8月8〜10日の部屋、送迎、夜間同行を確定する。
2. **Honey Valley宿自身**: 8月11〜15日の空室、UV＋白幕のowner許可、4WD上下時刻、料金を確定する。
3. **IISER観察者／Outreach**: 8月13〜15のうち最低1夜、できれば2夜のhostと正式入構を確定する。

この3回答が来る前に北部か南部を感覚で選ぶ必要はありません。ただし出発が8月7日なので、内部締切を8月2日夜に置き、確約されなかった地点は本線から外して航空券と宿を購入します。
