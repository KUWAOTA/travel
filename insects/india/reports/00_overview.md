# インド・アルナーチャルプラデーシュ遠征 事前調査サマリー

作成日: 2026-04-14

## 先に結論

- 最優先で詰めるべきは `入口空港` `PAP対応業者` `夜間灯火の可否` の3点です。
- 生息候補地の本命は `Ziro - Talley Valley 周辺`、次点は `Bomdila - Dirang - Sessa / Eaglenest 周辺`、遠征色が強い第三候補が `Roing - Mayudia - Dibang Valley 周辺` です。
- PAP は州観光サイト上では `approved local tour operator only` 扱いで、外国人は `USD 30 / 人` の royalty 案内があります。
- 灯火は、公的に「昆虫観察用ライトトラップ可」と明示した公開情報を見つけられませんでした。PAPで入る以上、業者経由で書面確認を取る前提で考えるのが安全です。

## MTGでの推奨意思決定

1. まず狙う地域を `Ziro / Talley` と `West Kameng` の2本に絞る
2. PAP業者は `Duyu Tours & Travels` `Boni Tours & Travels` `Abor Country Travels` に同時照会する
3. 灯火の可否が未回答なら、旅程は `観察・撮影中心 / 採集なし` 前提で仮置きする
4. 航空券は `大阪発を第一候補` にしつつ、価格差が大きければ `東京発` も許容する

## いまの推奨プラン

- 航空券の考え方:
  `大阪 → コルカタ(CCU)` または `大阪/東京 → グワハティ(GAU)` を起点に比較するのが現実的です。
- フィールドの考え方:
  まずは `Ziro - Talley Valley` を第一候補に据え、道路事情とPAPの組みやすさ次第で `Bomdila - Dirang - Sessa` を第二候補にします。
- 実務の考え方:
  すぐに3社へ概算見積りとPAP可否、夜間観察可否を同時送信し、返答速度と回答の具体性で業者を絞るのが最短です。

## 未確定事項

- 2026-08-08 から 2026-08-16 ちょうどの最安航空券は、サービスごとに表示差が大きく、完全確定には至っていません。
- 灯火、捕獲、採集、夜間移動の可否は公開情報だけでは確定できません。
- 宿の立地によって、実際に夜間観察しやすいかは大きく変わります。
