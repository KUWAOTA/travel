# 「彼女のポストが見つかった」前提での世界移住先比較

**前提条件**: 彼女（児童心理学研究者）のアカデミックポストがどの国でも見つかると仮定。
その場合、残りの条件で純粋に国を評価する：

1. 子供が英語を習得できる
2. ビザが通りやすい
3. 将来がある国
4. アジア人差別が少ない
5. 熱帯でクワガタカブトが熱い
6. 魚突きができる
7. 子育て環境が良い
8. SWエンジニア（Java/Python）のポストがある
9. 日系企業からの採用がありそう

**彼女のポストを外した途端、熱帯・昆虫・魚突きの重みが一気に上がる。**

## ライフステージ別おすすめ

### 子供が生まれる前（今〜2〜3年）：冒険期

**攻めるなら:**
```
第1候補: ボルネオ（コタキナバル）1〜2年
  → マンディブラリス採集、シパダンで魚突き
  → 生活費月15万円、リモートワークで日本の貯金を減らさない
  → 英語環境で生活力をつける

第2候補: コスタリカ 1年
  → ヘラクレス自己採集という人生の夢を叶える
  → 太平洋＋カリブ海の両方を制覇
  → スペイン語という第3言語の基礎
```

```
  → 冒険期の経験を活かした研究（彼女のフィールドワーク経験が論文に）
```

### 休暇・遠征（永住後）

```
年1〜2回の昆虫採集＆魚突き遠征
  → ボルネオ、パプア、コスタリカ、コロンビアへ
```
