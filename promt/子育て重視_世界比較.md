# 子育て・子供の将来メリット重視の移住先比較（全世界版）

**目的**: 彼女を説得するための材料。
**軸**: 「この国で育った子供は、将来どんなアドバンテージを持つか？」
**方法**: 全世界の国を子育て基準でフラットに評価。地域バイアスなし。

---

## 評価基準と配点

| 基準 | 配点 | 内容 |
|---|---|---|
| 教育の質 | /20 | PISA順位、教育システムの特徴、大学の質 |
| 子供の幸福度 | /15 | ユニセフ子供幸福度ランキング、メンタルヘルス |
| 安全（治安＋医療） | /15 | 犯罪率、医療水準、自然災害リスク |
| 言語アドバンテージ | /15 | 子供が習得する言語の将来的な市場価値 |
| パスポート・市民権 | /10 | ビザなし渡航先数、居住権の広がり |
| 子育て支援制度 | /10 | 育休、保育、手当、医療費 |
| 多文化環境 | /5 | 多様性の中で育つことによる適応力 |
| 彼女のポスト（児童心理） | /5 | 大学・研究機関の充実度 |
| 親のキャリア（SW＋日系） | /5 | 二人の生計が成り立つか |
| **合計** | **/100** | |
