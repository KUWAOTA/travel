## ブリスベンの海 — 日本の海で例えると？

### 結論：**沖縄本島〜奄美大島の海に近い**

| 項目 | ブリスベン周辺 | 沖縄本島 | 奄美大島 | 和歌山（串本） |
|---|---|---|---|---|
| 水温 | 21〜28℃ | 21〜29℃ | 20〜28℃ | 17〜27℃ |
| 透明度 | 10〜25m | 15〜30m | 15〜30m | 8〜20m |
| 魚影の濃さ | ★★ | ★ | ★★ | ○ |
| サンゴ | あり（亜熱帯型） | あり（熱帯型） | あり（亜熱帯型） | 一部あり |
| 大物回遊魚 | GT、マグロ、マッカレル | GT、マグロ | GT、カンパチ | カンパチ、ブリ |

### もう少し細かく

- **ゴールドコースト沖（車1時間南）** → **沖縄の慶良間諸島に近い感覚**
  - 透明度15〜25m、サンゴと岩礁が混在、GT・マグロが回遊
  - ただし慶良間ほど手付かずではなく、人工魚礁（沈船等）が多いのが特徴
  - 魚影の「濃さ」では慶良間に匹敵するかそれ以上

- **North Stradbroke Island（フェリー30分）** → **奄美大島の海に近い**
  - ビーチエントリーで透明度15〜20m
  - ウミガメ・マンタが常駐。レオパードシャーク（トラフザメ）も
  - 奄美のように「島の海」感があるが、ブリスベンから日帰りで行ける

- **サンシャインコースト沖（車1時間北）** → **屋久島〜奄美の中間**
  - Wolf Rock（マンタ集合ポイント）は日本でいう与那国島のハンマーヘッド的な存在
  - やや外洋感が強く、流れもある

### 日本との決定的な違い

1. **魚のサイズが全体的にデカい** — 日本で40cmのGTがブリスベンでは80cm〜1mが普通に出る
2. **スピアフィッシングが文化として根付いている** — 日本の漁業権問題がない。ライセンス制で合法的に楽しめる
3. **サメがいる** — ブルシャーク、タイガーシャーク、ホワイトチップ。スピアフィッシングでは魚の血が出るのでサメ対策（シャークシールド等）が必要。日本より明確にリスクが高い
4. **混雑していない** — 沖縄のビーチのような観光客の混雑がない。オーストラリアの海は広大

## 生活全般

### 気候

| 月 | 気温 | 降水量 | 備考 |
|---|---|---|---|
| 1月（真夏） | 22〜30℃ | 多い（雨季） | 湿度高め。京都の7月に似るが風がある分マシ |
| 4月 | 18〜27℃ | 少ない | ベストシーズン開始。日本の5月下旬の感覚 |
| 7月（真冬） | 10〜21℃ | 少ない | 日本の10月下旬くらい。コート不要の日も多い |
| 10月 | 16〜27℃ | 少ない | ベストシーズン。日本の5月 |

**京都との比較**: 冬が圧倒的に温暖（京都の底冷えがない）。夏は同程度に暑いが、京都の盆地蒸し暑さよりはマシ。年間晴天日300日は京都の約1.5倍。

### 生活費（2人暮らし想定、月額AUD→日本円は1AUD=100円換算）

| 項目 | 月額AUD | 月額円換算 | 備考 |
|---|---|---|---|
| 家賃（2BR、Sunnybank周辺） | A$1,500〜1,800 | 15〜18万円 | メルボルンの8割、シドニーの6割 |
| 食費（自炊中心） | A$600〜800 | 6〜8万円 | アジア食材はSunnybankで安く手に入る |
| 光熱費 | A$150〜200 | 1.5〜2万円 | 冬の暖房費がほぼ不要なのが大きい |
| 交通費 | A$150〜200 | 1.5〜2万円 | 車社会。公共交通はあるが車がほぼ必須 |
| 健康保険 | A$300〜400 | 3〜4万円 | ビザによる。永住権なればMedicare（公的保険）でカバー |
| 通信費 | A$80〜120 | 0.8〜1.2万円 | スマホ＋インターネット |
| 娯楽・雑費 | A$300〜500 | 3〜5万円 | |
| **合計** | **A$3,100〜4,100** | **31〜41万円** | |

**京都2人暮らしとの比較**: 京都で同程度の生活をすると月25〜35万円。ブリスベンは1〜2割高い程度。ただしSWエンジニアの給与がA$100K〜140K（1,000〜1,400万円）なので、**可処分所得は日本より大幅に増える**。

### 車について
- ブリスベンは**車社会**。シドニー・メルボルンより公共交通が弱い
- 中古車: A$10,000〜20,000（100〜200万円）で十分な車が買える
- 日本と同じ**左側通行・右ハンドル**なので運転に違和感なし
- 日本の免許でQLD州の免許に切り替え可能（試験なし、翻訳書類のみ）

### なぜSunnybankか

- ブリスベンCBDから南へ車20分 / バス40分
- **アジア系住民50%超**。中華系・ベトナム系・韓国系・日本人
- Sunnybank Plazaを中心にアジア系レストラン・スーパー・ベーカリーが密集
- 日本食材: アジア系スーパー（Hanaromart等）で味噌・醤油・豆腐・納豆が手に入る
- 治安: ブリスベンの中でも良好なエリア

### スピアフィッシングのルール（QLD州）

- **ライセンス不要**（釣りと同様）
- **スクーバ（タンク）使用禁止** — フリーダイビング（素潜り）のみ
- **Green Zone（完全禁漁）では全面禁止** — GBR内はゾーニングマップで確認が必要
- バッグリミット（持ち帰り上限）あり: 例）コーラルトラウト 7匹/日、スナッパー 5匹/日
- **サメ対策**: Sharkbanz（磁気バンド）やSharkshield（電気バリア）の装着推奨。ブルシャークは実際にGold Coast〜Brisbaneの河口域にいる

### 日本のスピアフィッシングとの違い

| | ブリスベン | 日本 |
|---|---|---|
| 合法性 | **完全合法**。ライセンス不要 | 漁業権の問題でほぼグレー〜違法。漁協に許可を取る必要 |
| 魚のサイズ | 大きい（GTは1m超、マグロも） | 小さめ |
| コミュニティ | 大きい。ショップ・クラブ・SNSグループ充実 | 小さい。情報が少ない |
| サメリスク | **高い**。対策必須 | ほぼない |
| 水温 | 年中快適（21〜28℃） | 季節差大きい |

## 移住ロードマップ（具体的なステップ）

### Phase 0: 準備（日本にいる間 / 0〜12ヶ月）

```
[ ] IELTS受験 → 目標スコア: Overall 6.5以上（各セクション6.0以上）
    - SWエンジニアのSkilled Visa (subclass 482/189)に必要
    - TOEIC 640からのステップアップは6〜12ヶ月の勉強で現実的
[ ] 彼女もIELTS受験 → 研究者ならAcademic Module、Overall 7.0目標
[ ] Skills Assessment（技術審査）申請
    - SWエンジニア → ACS（Australian Computer Society）に申請
    - 職務経歴書・大学の学位証明が必要
    - 審査に2〜3ヶ月かかる
[ ] UQの児童心理ポストをウォッチ
    - UQ Jobs（公式求人サイト）で Developmental Psychology / Child Psychology を定期検索
    - 彼女がUQの教授にコンタクトを取り始める（研究者ネットワーク）
[ ] 貯金目標: 最低A$20,000〜30,000（200〜300万円）
    - 渡航費、初期費用（敷金・家具・車）、3ヶ月分の生活費
```

### Phase 1: ビザ取得＆渡航（12〜18ヶ月）

```
ルートA: あなたが先に就職 → 482ビザ（雇用主スポンサー）
  - オーストラリアのIT企業から内定 → 企業がビザスポンサー
  - 彼女はパートナービザ（de facto partner）で同行可能
  - パートナービザで彼女も就労・研究可能

ルートB: 彼女が先にポスト獲得 → 482ビザ or 研究者ビザ
  - UQがスポンサーとなってビザ発行
  - あなたがパートナービザで同行

ルートC: 独立技術移民 → 189/190ビザ（ポイント制）
  - 年齢（29歳=30pt）+ 学歴（修士=15pt）+ 英語（IELTS 7.0=10pt）+ 職歴（5年=10pt）
  - 合計65pt以上で申請可能。SWエンジニアは職業リストに掲載
  - 最も自由度が高いが、審査に時間がかかる（6〜12ヶ月）
```

### Phase 2: 定着（渡航後1〜2年）

```
[ ] Sunnybankエリアで賃貸（最初は2BR apartment）
[ ] 中古車購入（A$15,000程度、トヨタ/マツダの中古が安心）
[ ] 現地のスピアフィッシングクラブに参加
[ ] 昆虫採集はD'Aguilar National Parkから開始
[ ] 彼女がUQで研究開始 or ポスト探し継続
[ ] 子供が生まれたら → Sunnybank Hills State Schoolエリアの持ち家を検討
```

### Phase 3: 永住権（渡航後2〜4年）

```
[ ] 482ビザ → 186ビザ（永住権）への切り替え
    - 同じ雇用主のもとで2年以上働いた後に申請可能
[ ] 永住権取得 → Medicare（公的医療保険）でカバー
[ ] 子供がオーストラリアで生まれれば自動的にオーストラリア国籍
```

## リスクと対策

| リスク | 深刻度 | 対策 |
|---|---|---|
| 彼女のUQポストが見つからない | 高 | Griffith大学、QUT（Queensland University of Technology）も候補に。またはメルボルンに切り替え |
