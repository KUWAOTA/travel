# 課長との相談戦略

## 目的
JICA応募とキャリアに関する希望を課長に相談し、会社としてのサポート可能性を探る

## 相談前の確認事項
- [ ] パートナーの時間制約を改めて確認（秋2026 or 春2027）
- [ ] 持病に関する健康診断スケジュール確認
- [ ] JICA応募に必要な書類・スケジュール確認
- [ ] 退職後のキャリア見通し（給与、ポジション等）

---

## 相談の流れ（推奨進め方）

### 1. オープニング（信頼構築）
- 現在の職場での経験に感謝を伝える
- 今後のキャリアについて相談したい旨を伝える
- 相手の時間があるか確認

### 2. 背景説明（文脈共有）
**話し方のポイント：突然の決断ではなく、時間をかけて検討してきたことを示す**

```
「電子部品メーカーでの経験を通じて、グローバルな視点から
社会に貢献することへの関心が高まってきました。
特に、国際協力の道としてJICAを検討しており、
課長にご相談させていただきたいと思っています」
```

### 3. 具体的な状況開示

#### 応募時期
- 秋2026（約6ヶ月以内）or 春2027（約10ヶ月以内）
- パートナーの事情による時間制約あり

#### 健康面の対応
「持病について、JICAの健康診断で問題がなければ
進めるという方針です。診断前から辞表を出す予定はありません」

#### HR確認済の情報
「現職参加は人事に確認した結果、不可とのことです」

### 4. 二つの道の提示

#### **案A：JICAに参加する場合**
```
辞職後にJICAの青年海外協力隊に参加したいと考えており、
以下のサポートをいただければ幸いです：

1) 退職手続きのスムーズ化
2) JICA応募に向けたご推薦状（可能であれば）
3) 帰国後のキャリアに関する相談対応
4) 帰国後のポジション検討（可能範囲での）
```

#### **案B：会社経由での海外派遣を検討する場合**
```
「もし会社から海外派遣や国際プロジェクトの機会があれば、
そちらの道も検討したいと思います。
現職のままグローバル経験を積むことで、
会社へのより大きな貢献もできると考えます」
```

### 5. スケジュール提示
- **秋2026応募の場合**：3〜4ヶ月の準備期間が必要
- **春2027応募の場合**：10ヶ月の準備期間
- **早めの意思決定が重要**（書類作成、選考、現職調整）

### 6. 次のステップの確認
```
「今後は、次の1on1で詳細をお聞きしたいと思います。
会社としての対応方針や可能性をご教示いただけると幸いです」
```

---

## 想定される課長の反応と対応

### 反応A：「会社のためにそのような手間をかけたくない」
**対応**：
- 辞職予定を伝える（会社に迷惑をかけないため早期通知）
- 引継ぎ期間を充分に取ることを約束
- 帰国後の再雇用は求めない姿勢を示す

### 反応B：「海外派遣の機会があるかもしれない」
**対応**：
- 情報感謝、具体的な打診を待つ
- JICAとの比較検討を提案
- 時間軸を確認（秋応募の場合は決断が必要）

### 反応C：「個人的には応援するが、会社としての対応は難しい」
**対応**：
- 理解を示す
- 最小限のサポート（推薦状等）の可能性を探る
- 退職手続きの標準フロー確認

---

## 相談後のアクション

- [ ] 課長からのフィードバックを整理
- [ ] パートナーと結果を共有・最終判断
- [ ] HR部門への正式な相談（必要に応じて）
- [ ] JICA応募（選択した場合）の書類準備開始
- [ ] 退職予定日の決定

---

## 心構え

1. **相手の立場を尊重**：課長も経営判断がある立場
2. **柔軟性を持つ**：案A/案Bの両立も視野に
3. **誠実さ**：グローバル志向は長期的なキャリア構想であることを示す
4. **決断力**：秋応募なら早期の判断が必要なことを明確にする
